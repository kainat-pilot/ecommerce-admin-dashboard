# ShopSphere - E-Commerce Admin Dashboard UI

## Project Description
ShopSphere is a complete, modern, and professional E-Commerce Admin Dashboard UI built entirely with **HTML5 and CSS3** — no JavaScript, no frameworks. It gives store admins a clean interface to monitor sales, manage products, track orders, view customers, and analyze reports, all fully responsive across desktop, tablet, and mobile devices.

## Technologies Used
- HTML5
- CSS3 (Flexbox, CSS Grid, CSS Variables, Media Queries, Transitions, `conic-gradient` charts)
- No JavaScript, no Bootstrap, no Tailwind, no frameworks of any kind

## Pages
1. **Dashboard (`index.html`)** — Welcome banner, stat cards (Revenue, Orders, Products, Customers), Sales Overview chart, Order Status donut chart, Recent Orders, Top Selling Products, Quick Actions.
2. **Products (`products.html`)** — Searchable, filterable product table with images, categories, prices, stock levels, status badges, edit/delete actions, and pagination.
3. **Orders (`orders.html`)** — Full order list with customer, product, date, total, payment method, and status badges (Pending, Processing, Completed, Cancelled).
4. **Customers (`customers.html`)** — Customer directory with profile photos, contact details, order history, and total amount spent.
5. **Reports (`reports.html`)** — Revenue and sales summary cards, CSS-only bar and donut charts, best selling products, and recent transactions.
6. **Settings (`settings.html`)** — Profile information, account preferences, notification toggles, and password/security UI.

## Features
- Fully responsive design (desktop, tablet, and mobile) using CSS Media Queries
- Mobile sidebar navigation using a pure CSS checkbox toggle (no JavaScript)
- Dropdown menus (notifications, profile) built with native HTML `<details>`/`<summary>` — no JavaScript
- CSS-only bar charts and donut charts using `conic-gradient`
- Reusable design system with CSS variables (colors, spacing, radius, shadows)
- Status badges, hover effects, and smooth CSS transitions throughout
- Consistent sidebar and top navbar across all pages with active-page highlighting
- Realistic dummy data across all pages

## How to Run the Project
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Navigate between pages using the sidebar links.

No build steps, installations, or dependencies are required — it's pure static HTML and CSS.
