# E-Commerce Admin Dashboard UI

A complete, modern, and professional E-Commerce Admin Dashboard UI developed using only HTML5 and CSS3 (Flexbox and Grid).

## Features
- Clean multi-page layout
- Completely responsive for Desktop, Tablet, and Mobile
- Custom HTML/CSS Bar Charts (No JS libraries used)
- Consistent Design System across all pages

## Project Pages
1. Dashboard (`index.html`)
2. Products (`products.html`)
3. Orders (`orders.html`)
4. Customers (`customers.html`)
5. Reports (`reports.html`)
6. Settings (`settings.html`)

## How to Run
Clone or download the repository and open `index.html` in any web browser.
